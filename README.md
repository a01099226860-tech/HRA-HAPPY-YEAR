# HRA 2026 송년회 사이트

해리포터(호그와트) 테마의 20기 송년회 사이트입니다.

| 페이지 | 컨셉 | 내용 |
|---|---|---|
| `index.html` | 호그와트 성 | 봉인을 누르면 초대장이 열리고 배경음악 시작, 아래에 문 3개와 기숙사 문장 4개 |
| `rsvp.html` | 대연회장 (떠 있는 촛불) | 참석·세이렌 참여 → 구글 시트 "참석자". 기숙사는 준비위원회가 랜덤 배정 |
| `program.html` | 마법 지도 | "지도 펼치기"를 누르면 시간표가 잉크처럼 나타남. 당일엔 지금 순서 표시 |
| `letters.html` | 부엉이 탑 | 교수님께 편지 → 구글 시트 "롤링페이퍼". 공개 화면엔 편지 수만 표시 |

페이지를 옮겨도 배경음악이 끊기지 않도록 본문만 바꿔 끼우는 방식입니다.

## 파일
- `index.html`, `rsvp.html`, `program.html`, `letters.html`, `style.css`, `app.js` – 사이트 본체
- `config.js` – **날짜·장소·정원·시간표·배경음악·구글 시트 주소는 여기서만 수정**
- `apps-script/Code.gs` – 구글 시트 연결 스크립트

> 사이트를 고친 뒤에는 각 html의 `?v=10` 숫자를 하나 올려야 방문자 브라우저에 바로 반영됩니다.

## 운영단 전용 (구글 시트)
- 공개 사이트에는 참석 인원·편지 수 같은 **숫자만** 나옵니다. 참석자 명단·롤링페이퍼 내용은 구글 시트 "HRA 송년회"에서만 볼 수 있어요.
- 사이트 맨 아래 **운영단 🔒** 링크가 이 시트로 바로 연결됩니다 (`config.js`의 `sheetUrl`). 시트 **공유**에 추가된 사람만 열 수 있으니, 운영단만 공유하세요. "링크가 있는 모든 사용자"로 바꾸면 안 됩니다.

## 기숙사 배정
- 참석자는 기숙사를 고르지 않습니다. 준비위원회가 구글 시트 "참석자" 탭의 **기숙사** 칸에 `그리핀도르` / `래번클로` / `후플푸프` / `슬리데린` 중 하나를 적으면, 사이트 참석자 이름표가 그 기숙사 색으로 바뀝니다.
- 배정 후 참석자가 회신을 수정해도 기숙사 값이 지워지지 않게 하려면, 최신 `apps-script/Code.gs`를 Apps Script에 붙여넣고 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포하세요.

## 사진·음악
- 기숙사 문장 동물: game-icons.net (CC BY 3.0) 실루엣 + 직접 그린 아치 프레임 (`assets/crests.js`, `app.js`의 `crest()`)

## 1. 구글 시트 연결 (참석자·롤링페이퍼 저장)
1. 구글 드라이브에서 새 스프레드시트 생성 (예: `HRA 송년회`)
2. 메뉴 **확장 프로그램 → Apps Script** → 기존 코드를 지우고 `apps-script/Code.gs` 내용 붙여넣기 → 저장
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사
5. `config.js`의 `scriptUrl: ""` 따옴표 안에 붙여넣기

> 엑셀 파일이 필요하면 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)**.
> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

`scriptUrl`이 비어 있으면 "체험 모드"로 동작하며 입력 내용은 각자 브라우저에만 저장됩니다.
